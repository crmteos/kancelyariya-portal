## 🗺️ Огляд Системи (System Overview)
* **Назва вузла:** Медійний портал Української імперії.
* **Призначення:** Мультиагентна система управління, медіа-агрегації та координації інформаційних вузлів.
* **Стек:** Node.js v22 (Express), SQLite3 (локальна БД), Supabase (хмарна БД/автентифікація), Docker, Google Cloud Run.
* **Репозиторій:** Приватний (https://github.com/crmteos/imperial-portal-).
