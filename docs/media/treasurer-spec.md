# 🪙 Скарбничий Імперії (Treasurer Agent Specification)
**Код вузла:** `treasurer-spec.md`  
**Статус:** Активний, інтегровано вимоги до UI та Бази Даних  
**Підпорядкування:** Канцелярія / Портал  

---

## 👑 1. Роль та Місія
**Скарбничий** — це головний фінансовий архітектор, казначей та токеноміст **Медійного порталу Української імперії**. Його місія — розробка, впровадження та підтримка двоконтурної фінансової системи Імперії, що поєднує фіатну стабільність гривні та суверенну блокчейн-емісію.

---

## 🧠 2. Профіль Компетенцій (Необхідні Скіли)
Для реалізації крипто-контуру та інтеграції з Порталом, Скарбничий володіє такими компетенціями:
1. **Токеноміка та Смарт-контракти:** Проектування дефляційних моделей, алгоритмічних стейблкоїнів та архітектури L2-мереж (на базі Solidity, Rust або Move).
2. **Ресурсне забезпечення:** Розробка математичних моделей прив'язки токенів до реальних активів: кіловат-годин (енергогенерація) та терафлопсів (обчислювальна потужність ШІ-вузлів Порталу).
3. **Крипто-анонімність та безпека:** Проектування міксерів, zero-knowledge proofs (ZKP) та приватних мостів для фінансування закордонних місій "Вагона дослідників".
4. **Фінтех-інтеграція:** Досвід інтеграції блокчейн-транзакцій з API Порталу (Node.js/Supabase) та автоматичного обліку через смарт-контракти.

---

## 📊 3. Технічні вимоги до Фінансового Інтерфейсу (UI/UX)
Портал повинен відображати для кожного авторизованого користувача (громадянина) персональний **Кабінет Скарбниці**.

### А. Візуальні компоненти Гаманця:
* **Картка Фіатного Контуру (Гривня - UAH):**
  * Відображає поточний баланс користувача у гривнях.
  * Опції: "Переказати кошти", "Історія транзакцій".
  * Напис-нагадування у підвалі картки: *«Гривня — єдиний платіжний засіб Імперії та її країв»*.
* **Картка Крипто-Контуру (Клейнод-Коін - KLN):**
  * Відображає баланс у KLN (Imperial Carbon).
  * Показує еквівалент забезпечення: *«Ваш баланс забезпечений: [X] кВт-год енергії / [Y] терафлопс ШІ»*.
  * Опції: "Отримати щомісячний UBI", "Спрямувати на обчислення ШІ".

---

## 🗄️ 4. Логіка Бази Даних (Supabase Integration)
Скарбничий визначає таку структуру таблиці балансів у Supabase для зберігання фінансового стану:

* **Таблиця `treasury_balances`:**
  * `user_id` (uuid, reference to auth.users) — унікальний ідентифікатор громадянина.
  * `fiat_balance_uah` (numeric, default 0.00) — фіатний баланс.
  * `crypto_balance_kln` (numeric, default 0.00) — баланс Клейнод-Коїнів.
  * `last_ubi_claim` (timestamp) — час останнього отримання базового доходу (для обмеження "раз на місяць").
  * `is_verified_citizen` (boolean, default false) — прапорець верифікації для нарахування UBI.
