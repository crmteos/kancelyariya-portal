# Канцелярія Української Імперії

Статичний портал із трьох сторінок: публічний медіапортал, приватна панель керування
та генератор дзеркальних указів. **Чистий HTML5 + Tailwind CSS через CDN + Vanilla JS** —
без бекенду, без бази даних, без платних залежностей. Бюджет: **$0**.

| Сторінка | Файл | Призначення |
|---|---|---|
| 📻 Публічний медіапортал | [`index.html`](index.html) | Новини, прямий ефір, світоглядні контури |
| 🔒 Панель Канцелярії | [`admin.html`](admin.html) | Приватна адмінка, вузли модулів, журнал подій |
| 📜 Генератор Указів | [`decrees.html`](decrees.html) | Створення указів, архів у `localStorage`, друк |
| ↪️ Редірект | [`public.html`](public.html) | Сумісний alias на `index.html` |

## Запуск локально

Портал — це статичні файли, тому достатньо будь-якого локального сервера:

```bash
python -m http.server 8000
# → http://localhost:8000/index.html
```

Відкривати файли через `file://` не рекомендовано: браузер блокуватиме
`localStorage` та запити до Gemini API.

## Тести

Автотести працюють на **Python 3 (тільки stdlib)** та **headless Chrome** через
Chrome DevTools Protocol. Жодних `pip install`, `npm install` чи Node.js не потрібно.

```bash
python tests/run_tests.py              # усі тести
python tests/run_tests.py decrees      # лише кейси, у назві яких є "decrees"
python tests/run_tests.py --headful    # з видимим вікном Chrome
```

Звіт пишеться у `tests/last_report.txt` одразу після кожного кейсу, тому
перерваний прогін не втрачає результатів. Шлях можна змінити через змінну
оточення `CHANCERY_REPORT`, а стек-трейс помилок увімкнути через `CHANCERY_TRACE=1`.

Перевіряються: структура всіх трьох сторінок, генерація указів у двох контурах,
архів, адаптивність (375 / 768 / 1280 px), стили друку, доступність зовнішніх
ресурсів і поведінка Gemini-інтеграції **без живих викликів до API**.

## 🤖 Gemini-підсилення (опціонально)

`decrees.html` уміє генерувати указ через **Google Gemini API** (Free Tier, $0).
Це необовʼязкове доповнення: без ключа працює вбудований офлайн-генератор.

**Як увімкнути:**

1. Отримайте ключ на [Google AI Studio](https://aistudio.google.com/apikey).
2. Відкрийте `decrees.html` → розділ «🤖 Gemini-підсилення».
3. Увімкніть перемикач **УВІМК** і вставте ключ у поле (воно приховане).
4. Натисніть «🔑 Перевірити ключ», потім «⚡ Згенерувати Указ».

**Безпека ключа:**

- ключ живе **лише у змінній у памʼяті вкладки** — він не потрапляє у
  `localStorage`, `sessionStorage`, `IndexedDB` чи будь-який файл;
- після перезавантаження сторінки ключ зникає;
- у репозиторії ключів **немає**, а `docs/.env` (якщо є) ігнорується `.gitignore`;
- відповідь Gemini екранується перед вставкою в DOM, тож модель не може
  впровадити HTML/скрипти на сторінку;
- за будь-якої помилки API (невірний ключ, quota, мережа) автоматично
  спрацьовує офлайн-фолбек — указ буде створено в будь-якому разі.

> ⚠️ Ключ API у браузері видно сторонньому коду на сторінці. Для приватного
> використання це прийнятно; для публічного деплою краще винести виклик на
> серверний проксі.

## Деплой на GitHub Pages

1. Виконайте `git init` (якщо ще не) та `git add .` / `git commit`.
2. Завантажте репозиторій на GitHub.
3. У репозиторії: **Settings → Pages → Source: `Deploy from a branch`**,
   гілка `main`, тека `/ (root)`.
4. Файл [`docs/.nojekyll`](.nojekyll) вже додано, щоб Jekyll не фільтрував
   файли з підкресленнями.

CI-воркфлоу [.github/workflows/pages.yml](.github/workflows/pages.yml)
автоматично перевіряє тести й публікує сайт.

## Структура

```
├── admin.html          # приватна панель
├── decrees.html        # генератор указів (+ Gemini)
├── public.html         # redirect-stub на index.html
├── .nojekyll           # для GitHub Pages
├── tests/
│   ├── cdp.py          # мінімальний клієнт Chrome DevTools Protocol
│   └── run_tests.py    # автотести (Python stdlib only)
└── docs/               # матеріали проєкту (env-файли ігноруються)
```
