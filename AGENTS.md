# Інструкції для ШІ-кодерів
- Зчитуй /PROJECT_SPEC.md та /PROJECT_STATE.md перед виконанням задач.
- Дотримуйся $0 бюджету: чистий HTML5, Tailwind CSS via CDN та Vanilla JS.
- Публічна частина в /index.html, приватна адмінка — в /admin.html.
- **Обов'язковий крок перед змінами фронтенду:** Przed внесенням будь-яких змін у фронтенд (index.html, admin.html, media_catalog.js), обов'язково зчитай chancery_manifest.json. Усі нові функції повинні узгоджуватися з цією JSON-архітектурою і не ламати існуючі ключі.
